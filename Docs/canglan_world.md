# 第一卷 · 世界本源

## 一、起源

太古之时，无天地，无光阴，唯有**虚海**——一片没有边界、没有上下的灰蒙之水。

虚海之中沉睡着一头巨兽，名**"溟"**。无人知其形貌，因为见过它的，都成了它梦的一部分。

**苍澜古界，是溟的一场梦。**

它梦见自己裂开：脊骨化为撑天的山，呼吸化为流转的风，左眼为日，右眼为月，一滴坠落的泪，成了滋养万物的**灵潮**。灵潮所过之处，万物有灵——人、妖、草木、山石，皆可吞吐灵机，踏上修行之路。

但梦，终有醒时。

古界最古老的巫歌这样唱：**"溟梦九转，已至第八。九醒之日，潮退界消。"**

如今，是第八次梦的尾声。

## 二、力量体系：三脉一道

古界生灵修行，共三条正统大道，源自溟的三种梦境本能，外加佛土一支另立的香火道。

### 气脉 · 炼己
吞吐天地灵机，淬炼肉身经脉。境界分九重：
**启灵 → 通脉 → 凝湖 → 汇海 → 化丹 → 婴变 → 神游 → 渡劫 → 临圣**

气脉修士是世间主流，御剑飞天、搬山填海皆出于此。中土宗门，十之八九为气脉传承。

### 魂脉 · 通幽
锤炼神魂，可离体神游、驭使亡魂、窥探命数。魂修不长寿——神魂太强，肉身反成朽坏的容器。南疆巫岭的根基，外人畏之，称"近鬼之道"。

### 缘脉 · 结契
缘修不炼己、不修魂，与天地间的"灵物"结下**缘契**——一条古鲸、一株神木、一道海眼、一座山。借其力，承其命。**缘在人在，缘尽人亡。** 缘修一生只能结一缘，东澜群岛独门传承。

### 香火道（西荒佛土）
不修身、不修魂、不结缘，专聚众生愿力。信众越虔，佛越高。佛土坚信此道是唯一正道，视三脉为"梦中人学梦话"。

# 第三卷 · 中土天原（人族故土）

万里沃野，大河**沧水**自西向东贯穿，古界文明的源头。

## 3.1 大雍王朝

- 立国八百载，定都**天京**，人口万万，如今的中土共主。
- 皇帝称"承天御主"，名义统御中土，实则与三大圣地（太一门、青云山、白鹿书院）共治天下。
- 皇室祖训第一条：**"狐鸣于殿，国祚将绝。"**（源于开国皇帝与妖皇月见的旧案）
- 如今的大雍太子正在青云山剑脉学剑——王朝与圣地之间最贵重的一枚人质，也是一条纽带。
- 朝堂之上，主战派（太一门背书）与主和派（白鹿书院支撑）因沧水之盟将尽而斗得不可开交。

## 3.2 太一门

**「太一神钟一响，千里山河定。」**

- 天下气脉魁首，三大圣地之首（自诩），门风古傲，以"正道执牛耳"自居。
- 镇派至宝**太一神钟**，钟声可定千里灵机。
- 当代掌教**玄霄子**，临圣境，已闭关六十年——有人说他在渡劫，有人说他早死了，太一门的沉默本身就是威慑。
- **异变**：玄霄子闭关的第六十年，守钟弟子报告：**钟内有第二道呼吸声**。太一门连夜封山。
- 对青云山的态度：明面同道，暗里巴不得它继续衰落——少一个圣地，正道话语权就多一分。
- 视佛土东渐为心腹大患，称"东渐之祸"。

## 3.3 ⛰ 青云山 · 三脉一宗（核心势力）

**「剑开云雾，符引天机，阵锁山河。」**

立山三千年，中土最古老的修行宗门。开派祖师**青云子**立下规矩：**三道并行，殊途同归。** 一气三分，各成一脉：

### 🗡 剑脉 · 磨剑峰
- 青云山的刀锋。剑修炼气养剑，本命剑与心神相连，讲究"一剑破万法"。
- 峰主**白无尘**，当世剑道前三，性情冷傲，三十年未下山。
- 不下山的两个原因：一，在等一个"值得出剑的人"；二，他发过誓——**再握剑，必是北渡沧水之日**（其师、上任剑脉峰主，战死于人妖大战最后一战）。

### 📜 符脉 · 听符阁
- 青云山的眼睛。符修以灵符推演天机、封印邪祟。中土各州郡的平安符、镇宅符十之六七出自听符阁——青云山千年香火人情，大半是符脉攒的。
- 阁主**苏妙音**，外表双十年华温婉女子，实际坐镇符脉一百七十年。
- 禁符阁深处锁着三张符，镇的不是妖，是**"名字"**——三个从古界历史上被抹去的人的名字。

### 🛡 阵脉 · 磐石台
- 青云山的脊梁。护山大阵**"九锁山河"**三千年未破。
- 中土流传："太一门的钟吓人，青云山的阵气人——你打得过他们每一个人，就是打不进那座山。"
- 台主**石敢当**，两米高的憨直大汉，阵道当世第一，最大的烦恼是"师兄师妹吵架，我拉不住"。

### 青云山的衰落（三层真相）

**第一层（世人皆知）：人才凋零。**
近百年来未出过一个临圣境。三脉峰主皆卡在渡劫境，后继无人。

**第二层（宗门隐痛）：九剑失三。**
镇山之宝**《青云九剑图》**——青云子亲手所绘九幅剑图，每幅藏一式通天剑意，剑脉真正的根基。一百年前**失窃其三**。守图长老当夜自绝于磨剑峰顶，留下血书四字："内贼难防。"
失窃案成悬案，三脉互相猜忌：剑脉说符脉那晚轮值，符脉说阵脉大阵那晚有一道"无人察觉的裂缝"，阵脉说剑脉监守自盗……百年积怨，三脉离心。

**第三层（无人知晓）：剑图失窃那晚，山下来过一个人。**
苏妙音追查百年，只查到一条线索：失窃当夜，有人看见一个**没有影子的人**从后山离开，走向沧水北岸——**古战场**。
而如今，那个三百年前走进古战场、三个月前走出来的人，正在往天京去。他怀里揣着的东西里，有**一幅剑图**。

## 3.4 白鹿书院

**「书院后山有白鹿，山长一言改江河。」**

- 不修杀伐，养**浩然气**。三大圣地之一。
- 山长**许观澜**，曾在大旱之年说一个"雨"字，沧水倒流三百里。
- 书院弟子遍布朝堂，大雍半朝官员出自白鹿门下——皇帝离不开，也睡不安稳。
- 人妖争端中拼死主和，但许观澜自己承认："这次的'和'字，快说不出口了。"
- **后山白鹿**：谁也记不清活了多少年，书院因它得名，它从不解释任何事。（全界最接近"知道溟之真相"的存在之一）

# 第四卷 · 北冥寒域（霜月妖庭）

## 4.1 概况

极夜之地，半年无日。三千年前人妖大战，妖族败退北冥，被迫立誓"**妖不过沧水**"。败军在冰天雪地重立秩序，建**霜月妖庭**，共尊一皇。

## 4.2 妖皇 · 月见

- 九千年道行的白狐，妖庭共主。
- 据她自己说，曾是人——**八百年前大雍开国皇帝的妃子**。王朝立国那年现出狐身，被逐出天京，走过沧水时一夜白头。
- 此话无人敢考证，但大雍皇室祖训第一条"狐鸣于殿，国祚将绝"正是由此而来。
- 庭下三十六洞大妖，各统一方。

## 4.3 庭内分裂

- **守誓派**：恪守沧水之盟，相信极夜之地尚能延续。
- **南归派**：大妖**赤霄**（一头赤蛟）为首，已在沧水北岸集兵。其言直白："极夜之地养不出第九千年道行。要么南渡沧水，要么坐等着潮退梦醒，大家一起死。"
- 月见的态度无人猜得透——她既未镇压南归派，也未给赤霄一兵一卒。

## 4.4 时间压力

**沧水之盟，只剩七年。**

# 第五卷 · 西荒佛土（黄金十二寺）

## 5.1 概况

万里黄沙，仅一条**苦海绿洲带**可活人。十二座黄金佛寺沿绿洲而建。佛土人相信：**此世越苦，来世越甜。** 修香火道，聚众生愿力。

## 5.2 不动明王

- 佛土最高存在，已在大雷音寺深处静坐三百年，不曾睁眼、不曾言语。
- 他的金身每年高一寸——三百年，已高过寺中佛塔。
- 寺中古钟，每逢大事自鸣，三百年间**已响九次**。
- 老僧私下传言：**钟响十二次，明王睁眼。睁眼所见之物，即为"来世"。**

## 5.3 东渐之祸

- 第九次钟响那天，西荒下了三天三夜的**金色雨**。
- 此后佛土开始向中土"化缘"——香火道第一次越过西荒边界。
- 太一门称其为"东渐之祸"；大雍朝廷则对滚滚而来的"虔信"束手无策——你无法向自愿的信徒宣战。
- 佛土的信仰是温柔的：不征税、不征兵，只要你的"来世"。

# 第六卷 · 东澜群岛（缘师之乡）

## 6.1 概况

东海之上三千岛屿，每岛一缘主，每缘主镇一方海眼。不修庙、不建城、不称帝。东澜人长寿、好酒、善歌，出海祭缘、归航谢缘，座右铭刻在每座岛的礁石上：**"缘来不拒，缘去不留。"**

## 6.2 潮议会

- 延续千年，每年大潮之夜，三十六位大缘主齐聚**听鲸岛**，议定东澜一年大事。
- 议事规矩奇特：不举手、不投票，各述己见后由**"鲸歌"定夺**——岛下深渊住着古界最后一头太古鲸**"归墟"**，它一声鲸歌，就是东澜的答案。

## 6.3 归墟与海眼之变

- 近五十年，鲸歌一年比一年低哑。潮议会秘而不宣，只称"归墟年纪大了"。
- 真相：**海眼在变浅。东海的灵潮，正在退。**
- 东澜的酒价骗不了人——祭缘的酒三年涨了五倍，缘主们在提前囤积说不出口的东西。
- 灵潮退，则缘契弱；缘契弱，则缘师亡。东澜是五域中对"潮退"最先知、也最怕的一域。

# 第七卷 · 南疆巫岭（九十九寨）

## 7.1 概况

十万大山，瘴雾万年不散。无国无朝，九十九寨各奉一位**祖神**——各寨先祖死后神魂不散、与大山融为一体的真实存在。

巫者修魂驭蛊，视生死为"过桥的往返"：葬俗是喜事，出生反而要哭——**"又来梦里走一遭，辛苦了。"**

## 7.2 巫岭守着的秘密

全古界只有巫岭的祖神们，一代代传守着那个所有大势力都在猜测、却只有巫岭敢直说的秘密：

**第八次梦快醒了。前七次梦醒时，什么都没能留下来。**

- 巫岭最深处有一座**无字碑**，碑下埋着七块颜色各异的石头——据说是**前七次世界的残骸**。
- 九十九寨存在的唯一使命，不是繁衍，不是强盛，而是**为第八次世界，留下一块不一样的石头。**

## 7.3 现状

- 九十九寨今年同时收到祖神的同一句话——**"石头，该准备了。"**
- 与青云山有一段三千年不断的默契：每年送山货、每年收回礼，从不留话（青云子立山前曾在巫岭住过十年）。

# 第八卷 · 沧水以北 · 古战场

五域之外，不在任何舆图上的地方。

- 三千年前人妖大战决战之地。那一战打得灵潮断流、沧水改道，双方战死者数以百万计，尸骨与断剑至今铺满百里荒原。
- 古战场常年灰雾笼罩，进入者十去九不回——不是有妖物，而是那里的"梦"太厚了：百万亡魂的执念沉在土里，走进去的人会渐渐分不清自己是活人，还是三千年前某个战死的残念。

三千年间，只有两个人活着走出来过：
1. **白无尘之师**——上任剑脉峰主，进去为寻找一柄失落的名剑，出来时道基已毁，三年后战死（对外称战死于人妖大战最后一战）。
2. **一个无名者**——三百年前走进去，**三个月前走了出来**。他正在往天京去，怀里揣着一幅青云剑图。

# 第十卷 · 时代：第八次梦的尾声

神眠历9742年，五域看似太平，底下的裂缝却在同时张开：

1. **沧水之盟，只剩七年。** 南归派赤霄集兵北岸，大雍主战派磨刀霍霍，白鹿书院拼死主和——但连许观澜都承认"和"字快说不出口。
2. **佛钟响了九次。** 第九次响起那天下金色雨三日，佛土开始向中土"化缘"，太一门称"东渐之祸"。
3. **东海灵潮在退。** 潮议会封锁消息，但祭缘酒三年涨五倍，缘主们在囤说不出口的东西。
4. **太一神钟六十年未响。** 守钟弟子报告钟内有第二道呼吸声，太一门连夜封山。
5. **巫岭九十九寨，同时收到祖神的话**——"石头，该准备了。"
6. **无名者从古战场走出，怀揣青云剑图，往天京去。** 他在沧水边遇白无尘。第二天，白无尘取下了尘封三十年的剑。

山雨欲来，而众生还在梦里。
