## 4. 设计红线（全资料库共用）

1. 任一经济 source 必须对应 sink，否则通胀（钻石当前裸露）。
2. 效果原子加新组件：先写 mutex + 默认属性，再写分派，否则战斗静默失效。
3. **随机效果禁止进原子**（P3 可预测支柱）；要随机走辅材兑底，白名单管理。指示物必须有 sink（source/sink 闭合）。区域目标只走合法配对（码表 §11 mutex）。
4. 所有 `[PLACEHOLDER]` 数值进 build 前必须过 paper prototype + playtest 失败信号定义。
5. 世界观换皮不换骨：7 属性与回路原子机制保留，只重做叙事外壳。
6. 商用原创声明：设定名称（玦港/虚渊/异兽/灵质/玦杯）均为占位，结构（现代都市+异界怪物投影成卡+素材造卡+公会+大赛）为品类惯例，不照搬任何现有游戏原设定。
7. 不承诺“会火”——只承诺循环好玩 + 每条数值有验证路径。
